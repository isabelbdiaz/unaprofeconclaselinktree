# Una Profe con clase | Linktree

Este repositorio contiene mi proyecto personal de Linktree. Soy maestra de Educación Primaria y diseñadora instruccional, y he creado este sitio web como un punto de acceso centralizado a mis redes sociales, mi tienda de recursos educativos y mis artículos de blog.

## Estructura del proyecto

- `index.html`: Página principal con enlaces a mis redes sociales, productos destacados y artículos.
- `style.css`: Hoja de estilos personalizada para el diseño visual.
- `main.js`: Script para la interacción de la galería de productos.
- `images/`: Carpeta con imágenes utilizadas en el sitio (logos, productos, iconos de redes, fondo, etc).

## Características
- Diseño responsivo y visualmente atractivo.
- Enlaces directos a mis cuentas de Instagram, TikTok, Twitch y Gumroad.
- Galería de productos destacados con acceso a mi tienda.
- Sección de artículos de blog donde comparto sobre educación y tecnología educativa.
